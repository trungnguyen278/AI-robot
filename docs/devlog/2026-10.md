# 2026-10

## 2026-10-15 — Project setup

**Done:** Analyzed the hardware limits of Luni_Robot; chose a Raspberry Pi 5 (8 GB) plus an ESP32-S3; named the repository `ai-robot`; created the repository skeleton (layout, conventions, design and portability rules, checklists for AI assistants, initial hardware documentation, concept v0, notes on the main parts).
**Decisions:** [ADR-0001](../decisions/0001-raspberry-pi-5-8gb.md), [ADR-0002](../decisions/0002-esp32-s3-body-controller.md), [ADR-0003](../decisions/0003-neutral-repo-naming.md).
**Problems / unfinished:** Open hardware issues in [`hardware/README.md`](../../hardware/README.md) (I2S conflict, servo bus adapter, servo current, powering the Pi through the header, emergency-stop scope). The arm design may change.
**Next:** Finalize the first parts order; answer the open questions in [`docs/architecture.md`](../architecture.md) (OS, ROS 2, language).

## 2026-10-15 — Raspberry Pi software skeleton

**Done:** Only the Pi 5 is fixed, so the Pi software comes first and the rest waits. Created the skeleton in [`software/`](../../software/README.md): modules talking through a message bus, hardware behind ports with simulated adapters, configuration profiles (`desktop`, `pi`), an optional C++ extension (pybind11) with Python fallbacks, tests and CI. It runs on any computer with `ai-robot --profile desktop`.
**Decisions:** [ADR-0004](../decisions/0004-pi-software-first.md) (supersedes ADR-0002); [ADR-0005](../decisions/0005-pi-software-platform.md) (Proposed).
**Problems / unfinished:** ADR-0005 awaits agreement. No real adapters yet; the AI backend interface is provisional; joint names and limits are placeholders until the arm design is fixed.
**Next:** Agree on ADR-0005; on the Pi, write the first real adapters (audio, camera, display); design the face.
