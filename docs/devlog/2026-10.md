# 2026-10

## 2026-10-15 — Project setup

**Done:** Analyzed the hardware limits of Luni_Robot; chose a Raspberry Pi 5 (8 GB); named the repository `ai-robot`; created the repository skeleton (layout, conventions, design and portability rules, checklists for AI assistants, initial hardware documentation, concept v0, notes on the main parts).
**Decisions:** [ADR-0001](https://github.com/trungnguyen278/ai-robot-design/blob/main/decisions/0001-raspberry-pi-5-8gb.md), [ADR-0002](https://github.com/trungnguyen278/ai-robot-design/blob/main/decisions/0002-esp32-s3-body-controller.md), [ADR-0003](https://github.com/trungnguyen278/ai-robot-design/blob/main/decisions/0003-neutral-repo-naming.md).
**Problems / unfinished:** Open hardware issues in [`hardware/README.md`](../../hardware/README.md) (I2S conflict, servo bus adapter, servo current, powering the Pi through the header, emergency-stop scope). The arm design may change.
**Next:** Finalize the first parts order; settle the software platform.

## 2026-10-15 — Design moved to ai-robot-design

**Done:** Moved the vision, architecture, previous-generation notes and ADRs to [ai-robot-design](https://github.com/trungnguyen278/ai-robot-design); this repository keeps code, hardware and the dev log. Made the documentation independent of the body microcontroller.
**Decisions:** [ADR-0004](https://github.com/trungnguyen278/ai-robot-design/blob/main/decisions/0004-pi-first-hardware-abstraction.md) — only the Raspberry Pi 5 is fixed; hardware sits behind ports with simulated adapters, so the Pi software is built first (supersedes ADR-0002). [ADR-0005](https://github.com/trungnguyen278/ai-robot-design/blob/main/decisions/0005-pi-software-platform.md) (software platform) is proposed.
**Problems / unfinished:** ADR-0005 is not agreed yet; the body microcontroller is not chosen.
**Next:** Agree on ADR-0005, then lay out `software/` (ports, `sim` adapters, profiles).
