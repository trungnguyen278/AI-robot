# Development log

One file per month, named `YYYY-MM.md`, with new entries appended at the end. How to write entries: the `devlog` checklist (`.claude/skills/devlog/SKILL.md`).

Entry template:

```markdown
## YYYY-MM-DD — <short title>

**Done:** …
**Decisions:** … (link ADRs)
**Problems / unfinished:** …
**Next:** …
```
