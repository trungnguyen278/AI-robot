# Nhật ký phát triển

Mỗi tháng một file `YYYY-MM.md`, mục mới thêm vào cuối. Cách ghi: skill `devlog`.

Mẫu một mục:

```markdown
## YYYY-MM-DD — <tiêu đề ngắn>

**Đã làm:** …
**Quyết định:** … (link ADR nếu có)
**Vấn đề / còn dở:** …
**Bước tiếp theo:** …
```
